# BLE dependency

IncubatorNimBLE-2.5.1.zip is the custom peripheral-only profile used by 2.2.2 and later. Install through Arduino Add .ZIP Library. Earlier 2.2.0/2.2.1 use upstream NimBLE-Arduino 2.5.1; older releases use built-in BLE. Follow the selected version README. All original license files are included.

本包为 2.2.2 及后续使用的定制 BLE 配置；2.2.0/2.2.1 使用上游 NimBLE-Arduino 2.5.1，更早版本使用核心内置 BLE，按各版说明选择。
